# Ranel — Founder Review Protocol

**Purpose:** make founder review fast without making the founder responsible for routine decisions.

## Review packet

Every material founder review should contain:

1. Decision.
2. Recommendation.
3. Evidence.
4. Main trade-off.
5. Risk if approved.
6. Risk if not approved.
7. Exact action after approval.

## Founder responses

### APPROVE

The recommendation becomes the working decision within its stated scope.

### APPROVE WITH CHANGES

The founder states only the changed parts. ChatGPT updates the decision record and Genspark receives the revised execution boundary.

### REJECT

The responsible layer returns with a replacement recommendation. The project should not remain stopped unless the rejected decision is a true blocking dependency.

### HOLD FOR MORE EVIDENCE

ChatGPT performs the required research or validation and returns a new evidence-based recommendation.

## Default

If a decision is below the material-decision threshold, no founder review is required.

## Review quality

Founder review should not become a second planning session. The AI layers are expected to do the research, comparison, drafting, implementation planning, and ordinary trade-off analysis first.

## Decision record

When a founder approves a material decision, record:

- decision;
- scope;
- date;
- any conditions;
- source/evidence;
- downstream dependency.

## Principle

> Founder review is a control point, not a bottleneck.
