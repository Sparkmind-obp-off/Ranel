# Ranel — Initial Promotion Policy

Date: 2026-10-03
Status: **DECIDED — INITIAL MARKET TEST**

## Decision

Ranel will use controlled **promo codes** rather than ad-hoc price negotiation.

Initial rules:
- maximum discount: **40%** from the approved base price;
- one promo code per order;
- no stacking with another promo code;
- each code must have an explicit start date and end date;
- each code must declare which product(s) it applies to;
- each code may have a redemption limit;
- discount is calculated from the approved product price before any legally required tax treatment;
- the customer-facing payable amount must be shown before payment;
- Ranel may create or retire promo codes without changing the base product prices;
- a promo code must never be used to misrepresent the normal price or create a false permanent-sale impression.

## Initial package examples

At the maximum 40% discount:
- Starter Rp39.000 → Rp23.400
- Growth Rp79.000 → Rp47.400
- System Rp149.000 → Rp89.400

These are examples of the rule, not automatically active promotions.

## Why 40%

40% is large enough to support launch experiments without making deep discounting the permanent anchor for a very low-priced entry product. The base prices remain the primary commercial reference.

## Governance

Creating a routine promo code inside these rules is operational and reversible.

Changes to the maximum discount, stacking rule, base prices, or an open-ended public campaign require a new commercial decision.

No promo code is active until the later commerce layer can calculate and record the discount deterministically.
