# User Journeys

## A. Visitor learns about Ranel
Arrives from a shared link/search → understands audience and offer → views barber page/available offer → asks a question or requests a pilot → reviews privacy information → submits necessary details → sees a truthful confirmation.
**Signal:** qualified inquiries, not page views alone.

## B. Barber requests a pilot
Reads scope/price/duration/deliverables → contacts Ranel → need is qualified manually → both sides agree scope, price, date, and success measure → agreement/consent recorded → delivery/check-ins tracked → results reviewed.

## C. Future product purchase
Views published offer and accurate price → checks deliverables/terms/refund policy → pays via verified provider or explicit manual process → payment is verified → receives product → can request support/refund as applicable. A redirect alone is not payment proof.

## D. Internal inquiry management (future)
Operator signs in securely → views restricted inquiry data → records next action/status → contacts using preferred method and consent → closes/converts/disqualifies → exports/deletes data according to policy.

## E. Future barber system
Business is onboarded into a tenant → owner configures services/workflows → authorized staff record events → owner views scoped reports/exports → business can request closure/export. This is future scope, not an implemented feature.
